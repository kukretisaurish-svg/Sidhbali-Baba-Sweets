# Sidhbali-Baba-Sweets
Sidhbali Baba Sweets – Website

Single-file Diwali sweet shop website (HTML, CSS and JavaScript in one file).

Features

Intro video that fades out, then the site fades in
3D firework bursts (canvas) and flickering diyas
Diwali sweets with weight choice and Add to cart
Combo packs
Cart and checkout: UPI (Fam) or cash on delivery
Delivery: free within 1 km, then Rs 20 per extra km (rounded up)
Shop gallery, reviews link and Google Maps directions

Things to edit

UPI_ID (near the end of the file): shop UPI ID
SHOP: address and Google Maps link (add lat and lng to switch on automatic delivery distance)
REVIEWS: add real customer reviews as {n:'Name',t:'Review text'}
PR: sweet prices per kg (sample prices now)
Combo prices: inside the combo cards in the HTML

Notes

The photos and video are embedded in the real .html file as base64. In the code below they are replaced with PUT_BASE64_OR_FILE_PATH_HERE:... placeholders. Use the .html file for the complete working site, or point each src to a normal file path.
